# Cofty

## <code>Introdução</code>

Cafty é um modelo de site feito para estudo e prática de estrutura front-end. O projeto é construído usando React com Next.js para renderização do lado do servidor e Tailwind CSS para estilo.

## <code>Pré-requisitos</code>
 
- [Node.js](https://nodejs.org/en/) (version 12 or higher)
- [npm](https://www.npmjs.com/) (version 6 or higher) or [yarn](https://yarnpkg.com/)

## <code>Configuração</code>
 
1. Clone o repositório:

```
git clone https://github.com/VictorBravim/Cofty.git
```

2. Navegue até o diretório do projeto:

```
cd Cofty
```

3. Instale as dependências:

```
npm install
or
yarn install
```

4. Execute o servidor de desenvolvimento:

```
npm run dev
```

## <code>Estrutura</code>

- **Nav.tsx:** Barra de navegação com links para diferentes seções do site.
- **Hero.tsx:** Seção Hero com imagem de fundo e texto introdutório.
- **Cards.tsx:** Exibe cartões de produtos com imagens e breves descrições.
- **About.tsx:** Seção Sobre que fornece informações sobre a cafeteria.
- **Promo.tsx:** Seção promocional com imagem de fundo.
- **Produto.tsx:** Seção de produtos listando diferentes produtos de café disponíveis para compra.
- **Contato.tsx:** Seção de contato com formulário para contato dos usuários.
